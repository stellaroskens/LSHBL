# GitHub

Origin is `https://github.com/stellaroskens/LSHBL.git`.

`main` is the primary branch. Feature work uses a branch and a pull request. `.github/workflows/ci.yml` installs dependencies, runs `npm test`, and runs `npm run build` on Node 22.

Do not push this project to `stellaroskens/WAHSB`. Do not force-push `main`.
