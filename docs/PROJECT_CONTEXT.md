# Project context

LSHBL is an independent public site for the Lebanon & Sweet Home High School Bowling League. The original WAHSB repository is read-only source material and must not receive commits.

The public site works without a database. Supabase, authentication, payments, and the admin dashboard are prepared as documents and a SQL migration, not as live systems.

The horizontal and square logos in `brand-assets/original/` are the league artwork. Do not redraw them. The November 15, 2025 raffle page is a design reference only.

No official contact email, fee schedule, roster, or practice time is published.
