# LSHBL

Public website for the Lebanon & Sweet Home High School Bowling League.

The site is a React, TypeScript, and Vite app. It does not include private student records, accounts, or payment processing. Another club's repository is not part of this project.

## Develop

Requires Node.js 22.

```bash
npm install
npm test
npm run build
npm run preview
```

Netlify build command: `npm run build`. Publish directory: `dist`.

## Contact email

Leave `VITE_CONTACT_EMAIL` unset until the league publishes an official address. Interest and sponsorship forms prepare a mailto draft only after that address exists. They do not store a submission.

See `docs/PROJECT_CONTEXT.md` for the current boundaries.
